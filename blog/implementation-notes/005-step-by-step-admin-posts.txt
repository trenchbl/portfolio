STEP 005 - ADMIN: CREATE, EDIT, AND DELETE POSTS
================================================


1. GOAL
-------
At the end of this step you will have:
- An admin area at /admin/posts listing all posts, drafts included, with
  their status
- A form to create and edit posts, with validation messages next to each
  field and nothing lost when there is a mistake
- Slugs generated from the title ("Grüße aus Köln" becomes
  "grusse-aus-koln"), or typed in by hand
- Publish and unpublish through a checkbox, previews of drafts, and delete
  with a confirmation
- "Post created", "Post saved", and "Post deleted" messages after each action
- The content column widened so long posts fit

WARNING: anyone who can reach the app can use /admin until step 006 adds
login. Only run this step on your own machine.


2. CONCEPTS
-----------
Post/Redirect/Get
  Every change is a POST. When it succeeds, the controller answers with a
  redirect to the list page instead of rendering a page directly. The
  browser then loads the list with a GET. Refreshing that page only repeats
  the harmless GET, never the POST, so a reload cannot create a post twice.
  When validation fails, there is no redirect: the controller renders the
  form again, with the input and the errors, in the same response.

Flash attributes
  A redirect starts a new request, so a normal model attribute would be
  lost. RedirectAttributes.addFlashAttribute stores the message in the
  session just long enough for the next request to show it, then removes
  it. That is why the "Post saved" message disappears on reload.

Never change data with GET
  Delete is a small form with a POST button, not a link. Browsers, link
  previews, and crawlers follow links freely, and a GET /delete link could
  delete posts nobody meant to delete. This also matters for step 006: CSRF
  protection covers POST requests, not GET.

The form object
  PostForm holds exactly the fields an author can edit, with Bean
  Validation rules (@NotBlank, @Size, @Pattern). The controller validates
  it with @Valid, and Spring puts the errors in BindingResult, which
  Thymeleaf shows next to each field. The entity never receives
  half-validated input, and fields that must not be edited through the form
  (id, timestamps) cannot be set by a crafted request.
  PostForm is a mutable class with getters and setters, because Spring
  binds request parameters through setters and th:field reads values
  through getters.

Two kinds of validation
  - Field rules (is the title empty? is the slug well-formed?) are
    annotations on PostForm and are checked before the service is called.
  - Rules that need the database (is the slug free?) are checked in the
    service, which throws SlugAlreadyUsedException. The controller turns
    that into an error on the slug field, so it looks like any other
    validation message.
  The unique constraint from step 003 is the final safety net: if two
  authors save the same slug at exactly the same moment, the database
  rejects the second one.

Choosing the slug
  If the author types a slug, it must be free, or they get an error. They
  chose it on purpose, so silently changing it would be surprising. If the
  slug field is empty, a slug is generated from the title and gets "-2",
  "-3", and so on until it is free. Slugify turns accented letters into
  plain ones (é becomes e) by splitting them into letter plus accent
  (Unicode NFD) and dropping the accent. Letters like ß and ø have no such
  split, so a small table maps them (ß becomes ss).

Publishing
  The checkbox maps to published_at:
  - checked, and the post was a draft: published_at = now
  - checked, and the post was already published: unchanged, so editing a
    typo does not move an old post to the top of the home page
  - unchecked: published_at = NULL, so the post is a draft again

Checkboxes in HTML forms
  A browser sends nothing at all for an unchecked checkbox. th:field adds a
  hidden field named _published. When Spring sees _published without
  published, it sets the value to false. Without it, unchecking the box
  would have no effect.

Widening a column on MySQL
  TEXT holds up to 64 KB. With multi-byte characters, a long post can hit
  that. MEDIUMTEXT holds 16 MB. Watch out: on MySQL, Liquibase's
  modifyDataType rewrites the whole column definition and drops NOT NULL,
  so the changeset adds the constraint back right after.

3.3 Slug generation

  Create blog/src/main/java/com/blog/post/Slugs.java:

    package com.blog.post;

    import java.text.Normalizer;
    import java.util.Locale;
    import java.util.Map;
    import java.util.regex.Pattern;

    final class Slugs {

        static final int MAX_LENGTH = 200;

        private static final Pattern DIACRITICS = Pattern.compile("\\p{M}+");
        private static final Pattern NON_ALPHANUMERIC = Pattern.compile("[^a-z0-9]+");
        private static final Pattern EDGE_DASHES = Pattern.compile("^-+|-+$");

        // Unicode normalisation splits "é" into "e" plus an accent, but these letters have no such split
        private static final Map<String, String> LETTERS_WITHOUT_DECOMPOSITION = Map.of(
                "ß", "ss",
                "æ", "ae",
                "œ", "oe",
                "ø", "o",
                "đ", "d",
                "ł", "l");

        private Slugs() {
        }

        /**
         * "Café & Crème: Part 2!" becomes "cafe-creme-part-2". Returns an empty
         * string if the text contains no letters or digits.
         */
        static String slugify(String text) {
            String lowerCase = text.toLowerCase(Locale.ROOT);
            for (Map.Entry<String, String> letter : LETTERS_WITHOUT_DECOMPOSITION.entrySet()) {
                lowerCase = lowerCase.replace(letter.getKey(), letter.getValue());
            }
            String withoutDiacritics = DIACRITICS.matcher(Normalizer.normalize(lowerCase, Normalizer.Form.NFD)).replaceAll("");
            String dashed = NON_ALPHANUMERIC.matcher(withoutDiacritics).replaceAll("-");
            String slug = EDGE_DASHES.matcher(dashed).replaceAll("");
            if (slug.length() > MAX_LENGTH) {
                slug = EDGE_DASHES.matcher(slug.substring(0, MAX_LENGTH)).replaceAll("");
            }
            return slug;
        }
    }

  Notes:
  - Locale.ROOT makes lower-casing behave the same on every machine. With
    a Turkish default locale, "I".toLowerCase() would give a dotless ı.
  - \p{M} matches Unicode "marks", the accents that NFD splits off.
  - The class is package-private and final with a private constructor. It
    is a helper for the post package only.
  - The source file must be saved as UTF-8 because of the ß and ø
    characters. Maven compiles as UTF-8 by default in Spring Boot projects.


3.4 The form object and new exceptions

  Create blog/src/main/java/com/blog/post/PostForm.java:

    package com.blog.post;

    import jakarta.validation.constraints.NotBlank;
    import jakarta.validation.constraints.Pattern;
    import jakarta.validation.constraints.Size;

    /**
     * The fields an author can edit. A mutable bean, because Spring MVC binds
     * form fields to it and Thymeleaf's th:field reads it back.
     */
    public class PostForm {

        @NotBlank(message = "Enter a title")
        @Size(max = 200, message = "Keep the title under 200 characters")
        private String title = "";

        @Size(max = Slugs.MAX_LENGTH, message = "Keep the slug under 200 characters")
        @Pattern(regexp = "^$|^[a-z0-9]+(-[a-z0-9]+)*$",
                message = "Use only lowercase letters, digits, and single dashes between words")
        private String slug = "";

        @Size(max = 500, message = "Keep the summary under 500 characters")
        private String summary = "";

        @NotBlank(message = "Write some content")
        @Size(max = 1_000_000, message = "The content is too long")
        private String content = "";

        private boolean published;

        static PostForm from(Post post) {
            PostForm form = new PostForm();
            form.setTitle(post.getTitle());
            form.setSlug(post.getSlug());
            form.setSummary(post.getSummary() == null ? "" : post.getSummary());
            form.setContent(post.getContent());
            form.setPublished(post.isPublished());
            return form;
        }

        public String getTitle() {
            return title;
        }

        public void setTitle(String title) {
            this.title = title;
        }

        public String getSlug() {
            return slug;
        }

        public void setSlug(String slug) {
            this.slug = slug;
        }

        public String getSummary() {
            return summary;
        }

        public void setSummary(String summary) {
            this.summary = summary;
        }

        public String getContent() {
            return content;
        }

        public void setContent(String content) {
            this.content = content;
        }

        public boolean isPublished() {
            return published;
        }

        public void setPublished(boolean published) {
            this.published = published;
        }
    }

  Notes:
  - The slug pattern allows an empty value ("^$|"), which means "generate
    it for me". Otherwise it allows words of a-z and 0-9 joined by single
    dashes.
  - The limit of 1,000,000 characters stays well below MEDIUMTEXT's 16 MB,
    even if every character takes the maximum 4 bytes in UTF-8.
  - The messages are written in the annotations. A multi-language site
    would move them to messages.properties instead.

    package com.blog.post;

    import org.springframework.http.HttpStatus;
    import org.springframework.web.bind.annotation.ResponseStatus;

    @ResponseStatus(HttpStatus.NOT_FOUND)
    public class PostNotFoundException extends RuntimeException {

        private PostNotFoundException(String message) {
            super(message);
        }

        public static PostNotFoundException forSlug(String slug) {
            return new PostNotFoundException("No published post with slug '" + slug + "'");
        }

        public static PostNotFoundException forId(Long id) {
            return new PostNotFoundException("No post with id " + id);
        }
    }

3.6 Service

  Replace PostService.java:

    package com.blog.post;

    import com.blog.markdown.MarkdownRenderer;
    import org.springframework.data.domain.Page;
    import org.springframework.data.domain.PageRequest;
    import org.springframework.data.domain.Sort;
    import org.springframework.stereotype.Service;
    import org.springframework.transaction.annotation.Transactional;

    import java.time.LocalDateTime;

    @Service
    @Transactional(readOnly = true)
    public class PostService {

        public static final int PAGE_SIZE = 5;
        public static final int ADMIN_PAGE_SIZE = 20;

        private static final Sort NEWEST_FIRST = Sort.by(Sort.Order.desc("publishedAt"), Sort.Order.desc("id"));
        private static final Sort RECENTLY_UPDATED_FIRST = Sort.by(Sort.Order.desc("updatedAt"), Sort.Order.desc("id"));
        private static final String FALLBACK_SLUG = "post";

        private final PostRepository postRepository;
        private final MarkdownRenderer markdownRenderer;

        PostService(PostRepository postRepository, MarkdownRenderer markdownRenderer) {
            this.postRepository = postRepository;
            this.markdownRenderer = markdownRenderer;
        }

        /**
         * @param pageNumber 1-based page number, as shown to visitors
         */
        public Page<PostSummary> findPublished(int pageNumber) {
            PageRequest pageRequest = PageRequest.of(pageNumber - 1, PAGE_SIZE, NEWEST_FIRST);
            return postRepository.findByPublishedAtIsNotNull(pageRequest).map(PostSummary::from);
        }

        public PostDetail findPublishedBySlug(String slug) {
            return postRepository.findBySlugAndPublishedAtIsNotNull(slug)
                    .map(this::toDetail)
                    .orElseThrow(() -> PostNotFoundException.forSlug(slug));
        }

        /**
         * All posts, drafts included. {@code pageNumber} is 1-based.
         */
        public Page<AdminPostItem> findAllForAdmin(int pageNumber) {
            PageRequest pageRequest = PageRequest.of(pageNumber - 1, ADMIN_PAGE_SIZE, RECENTLY_UPDATED_FIRST);
            return postRepository.findAll(pageRequest).map(AdminPostItem::from);
        }

        public PostForm getForm(Long id) {
            return PostForm.from(getPost(id));
        }

        /**
         * Like {@link #findPublishedBySlug}, but also shows drafts.
         */
        public PostDetail getPreview(Long id) {
            return toDetail(getPost(id));
        }

        @Transactional
        public Long create(PostForm form) {
            String slug = chooseSlug(form, null);
            Post post = new Post(form.getTitle().strip(), slug, blankToNull(form.getSummary()), form.getContent());
            if (form.isPublished()) {
                post.publish(LocalDateTime.now());
            }
            return postRepository.save(post).getId();
        }

        @Transactional
        public void update(Long id, PostForm form) {
            Post post = getPost(id);
            String slug = chooseSlug(form, id);
            post.update(form.getTitle().strip(), slug, blankToNull(form.getSummary()), form.getContent());
            if (form.isPublished() && !post.isPublished()) {
                post.publish(LocalDateTime.now());
            } else if (!form.isPublished() && post.isPublished()) {
                post.unpublish();
            }
        }

        @Transactional
        public void delete(Long id) {
            postRepository.delete(getPost(id));
        }

        private Post getPost(Long id) {
            return postRepository.findById(id).orElseThrow(() -> PostNotFoundException.forId(id));
        }

        /**
         * A slug typed by the author must be free. A slug generated from the
         * title gets a number appended until it is free.
         */
        private String chooseSlug(PostForm form, Long postId) {
            String requested = form.getSlug() == null ? "" : form.getSlug().strip();
            if (!requested.isEmpty()) {
                if (isTaken(requested, postId)) {
                    throw new SlugAlreadyUsedException(requested);
                }
                return requested;
            }

            String base = Slugs.slugify(form.getTitle());
            if (base.isEmpty()) {
                base = FALLBACK_SLUG;
            }
            String candidate = base;
            for (int number = 2; isTaken(candidate, postId); number++) {
                String suffix = "-" + number;
                candidate = base.substring(0, Math.min(base.length(), Slugs.MAX_LENGTH - suffix.length())) + suffix;
            }
            return candidate;
        }

        private boolean isTaken(String slug, Long postId) {
            return postId == null ? postRepository.existsBySlug(slug) : postRepository.existsBySlugAndIdNot(slug, postId);
        }

        private PostDetail toDetail(Post post) {
            return new PostDetail(
                    post.getTitle(),
                    post.getSlug(),
                    post.getSummary(),
                    markdownRenderer.toHtml(post.getContent()),
                    post.getPublishedAt());
        }

        private static String blankToNull(String value) {
            return value == null || value.isBlank() ? null : value.strip();
        }
    }

  Notes:
  - The write methods have a plain @Transactional, which overrides the
    class-level readOnly = true.
  - The admin list is sorted by updatedAt, so the post you just edited is
    at the top.
  - When the slug gets a number, the base is shortened if needed so the
    result stays within 200 characters.
  - An empty summary is stored as NULL, not as an empty string, so the
    templates' th:if="${post.summary}" checks keep working.


3.7 Controller

  Create blog/src/main/java/com/blog/web/AdminPostController.java:

    package com.blog.web;

    import com.blog.post.AdminPostItem;
    import com.blog.post.PostForm;
    import com.blog.post.PostService;
    import com.blog.post.SlugAlreadyUsedException;
    import jakarta.validation.Valid;
    import org.springframework.data.domain.Page;
    import org.springframework.http.HttpStatus;
    import org.springframework.stereotype.Controller;
    import org.springframework.ui.Model;
    import org.springframework.validation.BindingResult;
    import org.springframework.web.bind.annotation.GetMapping;
    import org.springframework.web.bind.annotation.ModelAttribute;
    import org.springframework.web.bind.annotation.PathVariable;
    import org.springframework.web.bind.annotation.PostMapping;
    import org.springframework.web.bind.annotation.RequestMapping;
    import org.springframework.web.bind.annotation.RequestParam;
    import org.springframework.web.server.ResponseStatusException;
    import org.springframework.web.servlet.mvc.support.RedirectAttributes;

    @Controller
    @RequestMapping("/admin/posts")
    class AdminPostController {

        private static final String FORM_VIEW = "admin/post-form";

        private final PostService postService;

        AdminPostController(PostService postService) {
            this.postService = postService;
        }

        @GetMapping
        String list(@RequestParam(defaultValue = "1") int page, Model model) {
            if (page < 1) {
                throw new ResponseStatusException(HttpStatus.NOT_FOUND);
            }
            Page<AdminPostItem> posts = postService.findAllForAdmin(page);
            if (page > 1 && page > posts.getTotalPages()) {
                throw new ResponseStatusException(HttpStatus.NOT_FOUND);
            }
            model.addAttribute("posts", posts);
            return "admin/posts";
        }

        @GetMapping("/new")
        String newPost(Model model) {
            model.addAttribute("post", new PostForm());
            return FORM_VIEW;
        }

        @PostMapping
        String create(@Valid @ModelAttribute("post") PostForm form, BindingResult bindingResult,
                      RedirectAttributes redirectAttributes) {
            if (bindingResult.hasErrors()) {
                return FORM_VIEW;
            }
            try {
                postService.create(form);
            } catch (SlugAlreadyUsedException e) {
                bindingResult.rejectValue("slug", "slug.taken", "Another post already uses this slug");
                return FORM_VIEW;
            }
            redirectAttributes.addFlashAttribute("message", "Post created");
            return "redirect:/admin/posts";
        }

        @GetMapping("/{id}/edit")
        String edit(@PathVariable Long id, Model model) {
            model.addAttribute("post", postService.getForm(id));
            model.addAttribute("postId", id);
            return FORM_VIEW;
        }

        @PostMapping("/{id}")
        String update(@PathVariable Long id, @Valid @ModelAttribute("post") PostForm form, BindingResult bindingResult,
                      Model model, RedirectAttributes redirectAttributes) {
            model.addAttribute("postId", id);
            if (bindingResult.hasErrors()) {
                return FORM_VIEW;
            }
            try {
                postService.update(id, form);
            } catch (SlugAlreadyUsedException e) {
                bindingResult.rejectValue("slug", "slug.taken", "Another post already uses this slug");
                return FORM_VIEW;
            }
            redirectAttributes.addFlashAttribute("message", "Post saved");
            return "redirect:/admin/posts";
        }

        @PostMapping("/{id}/delete")
        String delete(@PathVariable Long id, RedirectAttributes redirectAttributes) {
            postService.delete(id);
            redirectAttributes.addFlashAttribute("message", "Post deleted");
            return "redirect:/admin/posts";
        }

        @GetMapping("/{id}/preview")
        String preview(@PathVariable Long id, Model model) {
            model.addAttribute("post", postService.getPreview(id));
            model.addAttribute("preview", true);
            return "post";
        }
    }

  Notes:
  - BindingResult must come directly after the @Valid parameter. Without
    it, a validation error would become a 400 error page instead of
    reaching the method.
  - @ModelAttribute("post") names the form object "post" in the model,
    which is what the template's th:object refers to.
  - postId tells the template whether it is creating or editing. It is
    added before the validation check, so a form with errors still posts
    back to the right URL.
  - The preview reuses the public post template with a "preview" flag.

    shown again, HTML-escaped (the ' becomes &#39;).
  - deletingIsNotPossibleWithGet guards the "never change data with GET"
    rule.
