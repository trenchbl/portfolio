STEP 003 - POST DETAIL PAGES AND PAGINATION
===========================================


1. GOAL
-------
At the end of this step you will have:
- A slug column on posts (for example "why-liquibase-owns-the-schema"),
  added by a migration that also fills it in for existing rows
- Post pages at readable URLs: /posts/why-liquibase-owns-the-schema
- A styled 404 page for unknown posts, drafts, and unknown URLs, plus a
  generic error page
- A paginated home page (5 posts per page) with "Newer" and "Older" links
- More sample posts in development, so there is a second page to see


2. CONCEPTS
-----------
Slugs instead of ids in URLs
  /posts/why-liquibase-owns-the-schema says what the page is about, which
  helps readers and search engines, and does not reveal how many rows the
  table has. A unique constraint in the database guarantees that two posts
  can never share a URL. Step 005 generates slugs from titles when posts
  are created in the admin pages. For now, they come from the migration and
  the sample data.

Changing a table that already has data
  Adding a NOT NULL column to a table with rows takes three moves in one
  changeset: add the column as nullable, fill it in for the existing rows,
  then add the NOT NULL and UNIQUE constraints. If the fill-in produced a
  duplicate, the unique constraint fails and the whole changeset is rolled
  back, so you never end up half-migrated.
  (MySQL commits automatically after each schema change, so a "rollback" on
  MySQL really means Liquibase stops and records nothing. Test migrations
  on a copy of real data before running them in production.)

Never edit a changeset that has run, even in development
  Liquibase stores a checksum of every changeset it has run and refuses to
  start if a file changes afterwards. This happens easily in development:
  if the app restarts (DevTools) while you are still editing a changeset,
  it runs the half-finished version. Ways out, from safest to most drastic:
  - Write a new changeset that fixes the old one (always right in shared
    or production databases).
  - Development only, when the change does not affect what the changeset
    did (for example reordering lines): clear the stored checksum so
    Liquibase records the new one:
      UPDATE DATABASECHANGELOG SET MD5SUM = NULL WHERE ID = '<changeset id>';
  - Development only: reset the database with docker compose down -v.

Pagination: 1-based for visitors, 0-based for Spring Data
  Visitors see ?page=2. Spring Data's PageRequest counts from 0. The service
  takes the 1-based number and does the conversion in one place. The
  controller returns 404 for page 0, negative pages, and pages past the
  end, so every page URL either shows posts or clearly does not exist.
  Page 1 has no ?page parameter, so the home page has only one URL.

Stable sort order
  Posts are sorted by published_at, then by id. Without the second key, two
  posts published at the same moment could swap places between page loads
  and show up on two pages, or on none.

How 404 pages work in Spring Boot
  Throwing an exception annotated with @ResponseStatus(NOT_FOUND) makes
  Spring send a 404. Spring Boot's error handling then looks for
  templates/error/404.html, and falls back to templates/error.html for any
  other error. Unmatched URLs such as /no-such-page take the same route.
  No controller advice is needed.

MockMvc vs. a real server
  MockMvc (@WebMvcTest) checks the status code, but it does not forward to
  the error page, so it cannot show what visitors actually see. ErrorPageTest
  starts the real server on a random port and requests pages over HTTP with
  Java's built-in HttpClient.

3.1 Add the slug column

  Create blog/src/main/resources/db/changelog/changes/003-add-post-slug.xml:

    <?xml version="1.0" encoding="UTF-8"?>
    <databaseChangeLog
            xmlns="http://www.liquibase.org/xml/ns/dbchangelog"
            xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
            xsi:schemaLocation="http://www.liquibase.org/xml/ns/dbchangelog
                http://www.liquibase.org/xml/ns/dbchangelog/dbchangelog-latest.xsd">

        <changeSet id="003-add-post-slug" author="blog">
            <addColumn tableName="posts">
                <column name="slug" type="VARCHAR(200)" afterColumn="title"/>
            </addColumn>

            <!-- Backfill existing rows: "Why Liquibase owns the schema" becomes "why-liquibase-owns-the-schema" -->
            <sql>
                UPDATE posts
                SET slug = TRIM(BOTH '-' FROM LOWER(REGEXP_REPLACE(title, '[^A-Za-z0-9]+', '-')))
            </sql>

            <addNotNullConstraint tableName="posts" columnName="slug" columnDataType="VARCHAR(200)"/>
            <addUniqueConstraint tableName="posts" columnNames="slug" constraintName="uk_posts_slug"/>
        </changeSet>

    </databaseChangeLog>

  How the backfill works: REGEXP_REPLACE turns every run of characters that
  are not letters or digits into one "-", LOWER makes it lower case, and
  TRIM removes a leading or trailing "-". This changeset has no context, so
  it runs everywhere, including on data that exists in production.

  The unique constraint also creates an index, which the lookup by slug
  uses.

3.5 Service

  Replace PostService.java:

    package com.blog.post;

    import org.springframework.data.domain.Page;
    import org.springframework.data.domain.PageRequest;
    import org.springframework.data.domain.Sort;
    import org.springframework.stereotype.Service;
    import org.springframework.transaction.annotation.Transactional;

    @Service
    @Transactional(readOnly = true)
    public class PostService {

        public static final int PAGE_SIZE = 5;

        private static final Sort NEWEST_FIRST = Sort.by(Sort.Order.desc("publishedAt"), Sort.Order.desc("id"));

        private final PostRepository postRepository;

        PostService(PostRepository postRepository) {
            this.postRepository = postRepository;
        }

        /**
         * @param pageNumber 1-based page number, as shown to visitors
         */
        public Page<PostSummary> findPublished(int pageNumber) {
            PageRequest pageRequest = PageRequest.of(pageNumber - 1, PAGE_SIZE, NEWEST_FIRST);
            return postRepository.findByPublishedAtIsNotNull(pageRequest).map(PostSummary::from);
        }

        public PostDetail findPublishedBySlug(String slug) {
            return postRepository.findBySlugAndPublishedAtIsNotNull(slug)
                    .map(PostDetail::from)
                    .orElseThrow(() -> new PostNotFoundException(slug));
        }
    }

  Page.map(...) converts the entities to records and keeps the page
  information (page number, total pages), which the template needs for its
  links. Sort uses entity field names (publishedAt), not column names.

    import com.blog.post.PostService;
    import com.blog.post.PostSummary;
    import org.springframework.data.domain.Page;
    import org.springframework.http.HttpStatus;
    import org.springframework.stereotype.Controller;
    import org.springframework.ui.Model;
    import org.springframework.web.bind.annotation.GetMapping;
    import org.springframework.web.bind.annotation.RequestParam;
    import org.springframework.web.server.ResponseStatusException;

    @Controller
    class HomeController {

        private final PostService postService;

        HomeController(PostService postService) {
            this.postService = postService;
        }

        @GetMapping("/")
        String home(@RequestParam(defaultValue = "1") int page, Model model) {
            if (page < 1) {
                throw new ResponseStatusException(HttpStatus.NOT_FOUND);
            }
            Page<PostSummary> posts = postService.findPublished(page);
            if (page > 1 && page > posts.getTotalPages()) {
                throw new ResponseStatusException(HttpStatus.NOT_FOUND);
            }
            model.addAttribute("posts", posts);
            return "home";
        }

        @GetMapping("/about")
        String about() {
            return "about";
        }
    }

  Page 1 with no posts at all is still a valid page (it shows "No posts
  have been published yet."), which is why the second check has page > 1.
  A non-numeric value such as ?page=abc gets a 400 Bad Request from Spring
  automatically.

3.7 Templates

  In fragments/layout.html, add a pagination fragment between the header
  and the footer fragments:

    <nav th:fragment="pagination(page, baseUrl)" th:if="${page.totalPages > 1}" class="pagination" aria-label="Pagination">
        <a th:if="${page.hasPrevious()}" rel="prev" class="pagination__link"
           th:href="${page.number == 1} ? @{${baseUrl}} : @{${baseUrl}(page=${page.number})}">&larr; Newer posts</a>
        <span class="pagination__status"
              th:text="|Page ${page.number + 1} of ${page.totalPages}|">Page 1 of 2</span>

  How the numbers work: page.number is 0-based, so on the page visitors
  call "2", page.number is 1. The previous page is then page.number (1,
  which is the plain base URL) and the next is page.number + 2. The
  baseUrl parameter makes the fragment reusable for category, tag, and
  search pages in steps 007 and 008. |...| is Thymeleaf's string template
  syntax.

    package com.blog.post;

    import com.blog.TestcontainersConfiguration;
    import org.junit.jupiter.api.Test;
    import org.springframework.beans.factory.annotation.Autowired;
    import org.springframework.boot.data.jpa.test.autoconfigure.DataJpaTest;
    import org.springframework.context.annotation.Import;
    import org.springframework.data.domain.Page;
    import org.springframework.test.context.ActiveProfiles;

    import java.time.LocalDateTime;

    import static org.assertj.core.api.Assertions.assertThat;
    import static org.assertj.core.api.Assertions.assertThatThrownBy;

    @DataJpaTest
    @Import({TestcontainersConfiguration.class, PostService.class})
    @ActiveProfiles("test")
    class PostServiceTest {

        @Autowired
        private PostRepository postRepository;

        @Autowired
        private PostService postService;

        @Test
        void listsOnlyPublishedPostsNewestFirst() {
            savePublished("Older", LocalDateTime.of(2026, 1, 1, 10, 0));
            savePublished("Newer", LocalDateTime.of(2026, 2, 1, 10, 0));
            postRepository.save(new Post("Draft", "draft", null, "content"));

            assertThat(postService.findPublished(1).getContent())
                    .extracting(PostSummary::title)
                    .containsExactly("Newer", "Older");
        }

        @Test
        void splitsPostsIntoPages() {
            int total = PostService.PAGE_SIZE + 2;
            for (int i = 1; i <= total; i++) {
                savePublished("Post " + i, LocalDateTime.of(2026, 1, i, 10, 0));
            }

            Page<PostSummary> firstPage = postService.findPublished(1);
            Page<PostSummary> secondPage = postService.findPublished(2);

            assertThat(firstPage.getTotalPages()).isEqualTo(2);
            assertThat(firstPage.getContent()).hasSize(PostService.PAGE_SIZE);
            assertThat(firstPage.getContent().getFirst().title()).isEqualTo("Post " + total);
            assertThat(secondPage.getContent()).extracting(PostSummary::title).containsExactly("Post 2", "Post 1");
        }

        @Test
        void findsPublishedPostBySlug() {
            savePublished("Hello world", LocalDateTime.of(2026, 1, 1, 10, 0));

            assertThat(postService.findPublishedBySlug("hello-world").title()).isEqualTo("Hello world");
        }

        @Test
        void doesNotFindDraftsBySlug() {
            postRepository.save(new Post("Secret draft", "secret-draft", null, "content"));

            assertThatThrownBy(() -> postService.findPublishedBySlug("secret-draft"))
                    .isInstanceOf(PostNotFoundException.class);
        }

        @Test
        void doesNotFindUnknownSlugs() {
            assertThatThrownBy(() -> postService.findPublishedBySlug("does-not-exist"))
                    .isInstanceOf(PostNotFoundException.class);
        }

        private void savePublished(String title, LocalDateTime publishedAt) {
            Post post = new Post(title, title.toLowerCase().replace(' ', '-'), null, "content");
            post.publish(publishedAt);
            postRepository.save(post);
        }
    }

                    .andExpect(view().name("about"));
        }

        private static Page<PostSummary> pageOf(List<PostSummary> posts, int pageNumber, int totalPages) {
            long totalElements = (long) totalPages * PostService.PAGE_SIZE;
            return new PageImpl<>(posts, PageRequest.of(pageNumber - 1, PostService.PAGE_SIZE), totalElements);

    package com.blog.web;

    import com.blog.TestcontainersConfiguration;
    import org.junit.jupiter.api.Test;
    import org.springframework.beans.factory.annotation.Value;
    import org.springframework.boot.test.context.SpringBootTest;
    import org.springframework.context.annotation.Import;
    import org.springframework.test.context.ActiveProfiles;

    import java.net.URI;
    import java.net.http.HttpClient;
    import java.net.http.HttpRequest;
    import java.net.http.HttpResponse;

    import static org.assertj.core.api.Assertions.assertThat;

    /**
     * MockMvc does not forward errors to Spring Boot's error page, so this test
     * runs the real server to check what visitors actually see.
     */
    @SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
    @Import(TestcontainersConfiguration.class)
    @ActiveProfiles("test")
    class ErrorPageTest {

        @Value("${local.server.port}")
        private int port;

        private final HttpClient httpClient = HttpClient.newHttpClient();

        @Test
        void unknownPostShowsTheNotFoundPage() throws Exception {
            HttpResponse<String> response = get("/posts/does-not-exist");

            assertThat(response.statusCode()).isEqualTo(404);
            assertThat(response.body()).contains("Page not found").contains("site-header");
        }

        @Test
        void unknownUrlShowsTheNotFoundPage() throws Exception {
            HttpResponse<String> response = get("/no-such-page");

            assertThat(response.statusCode()).isEqualTo(404);
            assertThat(response.body()).contains("Page not found");
        }

        private HttpResponse<String> get(String path) throws Exception {
            HttpRequest request = HttpRequest.newBuilder(URI.create("http://localhost:" + port + path))
                    .header("Accept", "text/html")
                    .build();
            return httpClient.send(request, HttpResponse.BodyHandlers.ofString());
        }
    }

  Notes:
  - RANDOM_PORT starts the real Tomcat on a free port. Spring puts that
    port in the local.server.port property.
  - The Accept: text/html header matters. Without it, Spring Boot answers
    errors with JSON instead of the HTML page, which is how a browser
    request and an API request get different responses.
  - Checking for "site-header" proves the error page uses the shared
    layout, not Spring's default "Whitelabel Error Page".
