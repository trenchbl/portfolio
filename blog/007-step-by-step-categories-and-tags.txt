STEP 007 - CATEGORIES AND TAGS
==============================


1. GOAL
-------
At the end of this step you will have:
- Exactly one category per post, and any number of tags
- Pages for /categories/{slug} and /tags/{slug}, with pagination
- The category and tags on every post card and post page, as links
- A category list and a tags field in the admin post form. New tags are
  created when you save, and tags that no post uses any more disappear.
- An admin page at /admin/categories to add and delete categories
- Existing posts moved into a "General" category by the migration
- Lists of posts loaded with a fixed number of queries, however many
  posts are on the page


2. CONCEPTS
-----------
Two kinds of relationship
  - Category: many posts belong to one category. That is a foreign key
    column posts.category_id, mapped with @ManyToOne.
  - Tags: a post has many tags, and a tag belongs to many posts. A column
    cannot hold that, so a join table post_tags holds one row per
    (post, tag) pair, mapped with @ManyToMany and @JoinTable. Its primary
    key is the pair itself, so the same tag cannot be added to a post
    twice.

Adding a required column to a table with data
  posts.category_id must be NOT NULL, but the existing rows have no
  category. The migration therefore runs in three steps:
  1. Add the column, allowing NULL.
  2. Fill it in (here: every post goes into "General").
  3. Add the NOT NULL and foreign key constraints.
  This is the same pattern as the slug column in step 003. "General" is
  not sample data: every installation needs it for its existing posts, so
  its insert has no dev context.

Foreign keys and ON DELETE
  - fk_posts_category has no ON DELETE rule, so the database refuses to
    delete a category that still has posts. The service checks this first
    to give a clear answer. The foreign key is the safety net.
  - The post_tags foreign keys use ON DELETE CASCADE. Deleting a post or a
    tag removes its rows in the join table, which are meaningless on their
    own.

LAZY loading and the N+1 problem
  @ManyToOne loads eagerly by default: every query for posts would also
  load their categories, whether needed or not. The mapping sets
  fetch = LAZY, so Hibernate loads the category the first time it is
  used. Collections like the tags are lazy by default.
  Lazy loading has a trap. A page of 5 posts would load each post's
  category and tags one at a time: 1 query for the posts plus 2 per post,
  so "N+1" queries. The setting hibernate.default_batch_fetch_size=20
  makes Hibernate load the categories (and the tags) of up to 20 posts in
  one query with WHERE id IN (...). The home page now needs 4 queries
  (posts, count, categories, tags), however many posts it shows.
  With open-in-view=false (step 002), lazy data must be loaded inside the
  service's transaction. That is why the services turn entities into
  records (PostSummary and others) before returning them.

A set of tags
  Post.tags is a Set: a post cannot have the same tag twice. A Set has no
  order, so TagLink.sorted sorts the tags by name for display.

Tags are typed, categories are chosen
  Categories are a short, curated list, so the form offers a select box
  and the admin manages the list on its own page. Tags are informal and
  numerous, so the author types them, separated by commas. The service
  then:
  - turns each name into a slug ("Spring Boot" becomes spring-boot)
  - treats names with the same slug as the same tag, so "Spring Boot" and
    "spring-boot" never become two tags
  - reuses existing tags and creates the missing ones
  - after an update or delete, removes tags that no post uses any more,
    so dead tags do not stay in the hint list
  The rules (at most 10 tags, each at most 30 characters, each with a
  letter or digit) are checked in TagNames. A problem becomes an error on
  the tags field, just like a taken slug.

Shared code in the web layer
  Four controllers now check page numbers the same way (page 0 or past
  the end is a 404). That logic moves into a small PageNumbers helper. The
  post card moves into a Thymeleaf fragment, so the home page and the
  category and tag pages show posts the same way.

    package com.blog.post;

    import org.springframework.data.jpa.repository.JpaRepository;
    import org.springframework.data.jpa.repository.Modifying;
    import org.springframework.data.jpa.repository.Query;

    import java.util.Collection;
    import java.util.List;
    import java.util.Optional;

    interface TagRepository extends JpaRepository<Tag, Long> {

        Optional<Tag> findBySlug(String slug);

        List<Tag> findBySlugIn(Collection<String> slugs);

        /**
         * Removes tags that no post uses any more. Flushes first, so tag changes
         * made earlier in the transaction are already in the database.
         */
        @Modifying(flushAutomatically = true)
        @Query("delete from Tag t where not exists (select 1 from Post p join p.tags pt where pt = t)")
        int deleteUnused();
    }

  A bulk delete runs directly in the database and skips the persistence
  context. Without flushAutomatically, the post_tags changes from the same
  transaction would still be waiting in memory, and the query would see
  the old rows.

3.5 Parsing tags

  blog/src/main/java/com/blog/post/TagNames.java:

    package com.blog.post;

    import java.util.LinkedHashMap;
    import java.util.Map;
    import java.util.regex.Pattern;

    final class TagNames {

        static final int MAX_TAGS = 10;
        static final int MAX_LENGTH = 30;

        private static final Pattern WHITESPACE = Pattern.compile("\\s+");

        private TagNames() {
        }

        /**
         * Splits "Spring Boot, testing" into tag names, keyed by slug. Blank
         * entries are ignored, and names with the same slug count once, so
         * "Spring Boot, spring-boot" is a single tag.
         *
         * @throws InvalidTagsException with a message for the author
         */
        static Map<String, String> parse(String input) {
            Map<String, String> namesBySlug = new LinkedHashMap<>();
            if (input == null) {
                return namesBySlug;
            }
            for (String part : input.split(",")) {
                String name = WHITESPACE.matcher(part.strip()).replaceAll(" ");
                if (name.isEmpty()) {
                    continue;
                }
                if (name.length() > MAX_LENGTH) {
                    throw new InvalidTagsException("Keep each tag to " + MAX_LENGTH + " characters or fewer: \"" + name + "\"");
                }
                String slug = Slugs.slugify(name);
                if (slug.isEmpty()) {
                    throw new InvalidTagsException("Each tag needs at least one letter or digit: \"" + name + "\"");
                }
                namesBySlug.putIfAbsent(slug, name);
            }
            if (namesBySlug.size() > MAX_TAGS) {
                throw new InvalidTagsException("Use at most " + MAX_TAGS + " tags");
            }
            return namesBySlug;
        }
    }

  The messages contain what the author typed. That is safe, because
  th:errors escapes HTML like th:text does.

        public CategoryLink getCategory(String slug) {
            return categoryRepository.findBySlug(slug)
                    .map(CategoryLink::from)
                    .orElseThrow(() -> CategoryNotFoundException.forSlug(slug));
        }

        public Page<PostSummary> findPublishedByCategory(String categorySlug, int pageNumber) {
            return postRepository.findByCategory_SlugAndPublishedAtIsNotNull(categorySlug, publicPage(pageNumber))
                    .map(PostSummary::from);
        }

        /**
         * @throws TagNotFoundException if there is no such tag
         */
        public TagLink getTag(String slug) {
            return tagRepository.findBySlug(slug)
                    .map(TagLink::from)
                    .orElseThrow(() -> new TagNotFoundException(slug));
        }

        public Page<PostSummary> findPublishedByTag(String tagSlug, int pageNumber) {
            return postRepository.findByTags_SlugAndPublishedAtIsNotNull(tagSlug, publicPage(pageNumber))
                    .map(PostSummary::from);
        }

        public PostDetail findPublishedBySlug(String slug) {
            return postRepository.findBySlugAndPublishedAtIsNotNull(slug)
                    .map(this::toDetail)
                    .orElseThrow(() -> PostNotFoundException.forSlug(slug));
        }

        /**
         * All posts, drafts included. {@code pageNumber} is 1-based.
         */
        public Page<AdminPostItem> findAllForAdmin(int pageNumber) {
            PageRequest pageRequest = PageRequest.of(pageNumber - 1, ADMIN_PAGE_SIZE, RECENTLY_UPDATED_FIRST);
            return postRepository.findAll(pageRequest).map(AdminPostItem::from);
        }

        /**
         * For the hint next to the tags field in the admin form.
         */
        public List<String> findAllTagNames() {
            return tagRepository.findAll(Sort.by("name")).stream().map(Tag::getName).toList();
        }

        public PostForm getForm(Long id) {
            return PostForm.from(getPost(id));
        }

        /**
         * Like {@link #findPublishedBySlug}, but also shows drafts.
         */
        public PostDetail getPreview(Long id) {
            return toDetail(getPost(id));
        }

        /**
         * @throws InvalidTagsException     if the tags field cannot be used as it is
         * @throws SlugAlreadyUsedException if the typed slug belongs to another post
         */
        @Transactional
        public Long create(PostForm form) {
            Map<String, String> tagNames = TagNames.parse(form.getTags());
            Category category = getCategoryById(form.getCategoryId());
            String slug = chooseSlug(form, null);
            Post post = new Post(form.getTitle().strip(), slug, blankToNull(form.getSummary()), form.getContent(), category);
            post.replaceTags(findOrCreateTags(tagNames));
            if (form.isPublished()) {
                post.publish(LocalDateTime.now());
            }
            return postRepository.save(post).getId();
        }

        /**
         * @throws InvalidTagsException     if the tags field cannot be used as it is
         * @throws SlugAlreadyUsedException if the typed slug belongs to another post
         */
        @Transactional
        public void update(Long id, PostForm form) {
            Post post = getPost(id);
            Map<String, String> tagNames = TagNames.parse(form.getTags());
            Category category = getCategoryById(form.getCategoryId());
            String slug = chooseSlug(form, id);
            post.update(form.getTitle().strip(), slug, blankToNull(form.getSummary()), form.getContent(), category);
            post.replaceTags(findOrCreateTags(tagNames));
            if (form.isPublished() && !post.isPublished()) {
                post.publish(LocalDateTime.now());
            } else if (!form.isPublished() && post.isPublished()) {
                post.unpublish();
            }
            tagRepository.deleteUnused();
        }

        @Transactional
        public void delete(Long id) {
            postRepository.delete(getPost(id));
            tagRepository.deleteUnused();
        }

        private Post getPost(Long id) {
            return postRepository.findById(id).orElseThrow(() -> PostNotFoundException.forId(id));
        }

        private Category getCategoryById(Long id) {
            return categoryRepository.findById(id).orElseThrow(() -> CategoryNotFoundException.forId(id));
        }

        /**
         * Reuses the tags that already exist and creates the others.
         */
        private List<Tag> findOrCreateTags(Map<String, String> namesBySlug) {
            Map<String, Tag> existing = tagRepository.findBySlugIn(namesBySlug.keySet()).stream()
                    .collect(Collectors.toMap(Tag::getSlug, Function.identity()));
            List<Tag> tags = new ArrayList<>();
            namesBySlug.forEach((slug, name) -> {
                Tag tag = existing.get(slug);
                tags.add(tag != null ? tag : tagRepository.save(new Tag(name, slug)));
            });
            return tags;
        }

        // chooseSlug and isTaken stay exactly as in step 005

        private PostDetail toDetail(Post post) {
            return new PostDetail(
                    post.getTitle(),
                    post.getSlug(),
                    post.getSummary(),
                    markdownRenderer.toHtml(post.getContent()),
                    post.getPublishedAt(),
                    CategoryLink.from(post.getCategory()),
                    TagLink.sorted(post.getTags()));
        }

        private static PageRequest publicPage(int pageNumber) {
            return PageRequest.of(pageNumber - 1, PAGE_SIZE, NEWEST_FIRST);
        }

        private static String blankToNull(String value) {
            return value == null || value.isBlank() ? null : value.strip();
        }
    }

    package com.blog.web;

    import org.springframework.data.domain.Page;
    import org.springframework.http.HttpStatus;
    import org.springframework.web.server.ResponseStatusException;

    /**
     * Page numbers in URLs start at 1. Pages that cannot exist are 404s, so
     * search engines do not index endless empty pages.
     */
    final class PageNumbers {

        private PageNumbers() {
        }

        static void requireValid(int pageNumber) {
            if (pageNumber < 1) {
                throw new ResponseStatusException(HttpStatus.NOT_FOUND);
            }
        }

        /**
         * Page 1 always exists, so an empty list can show its "nothing here" message.
         */
        static <T> Page<T> requireExisting(int pageNumber, Page<T> page) {
            if (pageNumber > 1 && pageNumber > page.getTotalPages()) {
                throw new ResponseStatusException(HttpStatus.NOT_FOUND);
            }
            return page;
        }
    }

    import jakarta.validation.Valid;
    import org.springframework.stereotype.Controller;
    import org.springframework.ui.Model;
    import org.springframework.validation.BindingResult;
    import org.springframework.web.bind.annotation.GetMapping;
    import org.springframework.web.bind.annotation.ModelAttribute;
    import org.springframework.web.bind.annotation.PathVariable;
    import org.springframework.web.bind.annotation.PostMapping;
    import org.springframework.web.bind.annotation.RequestMapping;
    import org.springframework.web.servlet.mvc.support.RedirectAttributes;

    @Controller
    @RequestMapping("/admin/categories")
    class AdminCategoryController {

        private static final String VIEW = "admin/categories";

        private final CategoryService categoryService;

        AdminCategoryController(CategoryService categoryService) {
            this.categoryService = categoryService;
        }

        @GetMapping
        String list(Model model) {
            model.addAttribute("category", new CategoryForm());
            return showList(model);
        }

        @PostMapping
        String create(@Valid @ModelAttribute("category") CategoryForm form, BindingResult bindingResult,
                      Model model, RedirectAttributes redirectAttributes) {
            if (bindingResult.hasErrors()) {
                return showList(model);
            }
            try {
                categoryService.create(form);
            } catch (InvalidCategoryNameException e) {
                bindingResult.rejectValue("name", "name.invalid", e.getMessage());
                return showList(model);
            }
            redirectAttributes.addFlashAttribute("message", "Category created");
            return "redirect:/admin/categories";
        }

        @PostMapping("/{id}/delete")
        String delete(@PathVariable Long id, RedirectAttributes redirectAttributes) {
            categoryService.delete(id);
            redirectAttributes.addFlashAttribute("message", "Category deleted");
            return "redirect:/admin/categories";
        }

        private String showList(Model model) {
            model.addAttribute("categories", categoryService.findAll());
            return VIEW;
        }
    }

  Troubleshooting
  - "Schema validation: missing table [categories]" (or post_tags): the
    changelog files are not in db.changelog-master.xml, or the app ran
    with an old target/classes. Run .\mvnw clean spring-boot:run.
  - "LazyInitializationException: could not initialize proxy ... no
    session": a lazy category or tag was used outside a transaction,
    usually in a template. Map entities to records inside the service, as
    PostSummary.from does.
  - The category select is empty after a validation error: the controller
    returns FORM_VIEW directly instead of showForm(model).
  - "Cannot delete or update a parent row: a foreign key constraint
    fails": a category with posts was deleted directly in the database.
    Move its posts to another category first.
  - 409 when deleting a category: it still has posts (a draft counts too).
    The admin list hides the button in that case, so reload the page.
