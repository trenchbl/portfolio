===============================================================================
STEP-BY-STEP GUIDE: MYSQL DATABASE IN DOCKER CONTAINER
===============================================================================

This guide explains how to run a MySQL database as a Docker container for your
blog application.

===============================================================================
PREREQUISITES
===============================================================================

1. Docker Desktop installed and running
   - Download from: https://www.docker.com/products/docker-desktop
   - Verify installation: docker --version

===============================================================================
STEP 1: PULL MYSQL DOCKER IMAGE
===============================================================================

Open a terminal/PowerShell and run:

    docker pull mysql:8.0

This downloads the MySQL 8.0 image. You can use other versions like:
- mysql:latest (latest version)
- mysql:5.7 (older stable version)

===============================================================================
STEP 2: RUN MYSQL CONTAINER (BASIC)
===============================================================================

Run MySQL container with basic configuration:

    docker run --name blog-mysql ^
        -e MYSQL_ROOT_PASSWORD=rootpassword ^
        -e MYSQL_DATABASE=blogdb ^
        -e MYSQL_USER=bloguser ^
        -e MYSQL_PASSWORD=blogpass ^
        -p 3306:3306 ^
        -d mysql:8.0

Explanation of parameters:
- --name blog-mysql         : Container name
- -e MYSQL_ROOT_PASSWORD    : Root user password
- -e MYSQL_DATABASE         : Creates database on startup
- -e MYSQL_USER             : Creates application user
- -e MYSQL_PASSWORD         : Password for application user
- -p 3306:3306              : Maps port 3306 (host:container)
- -d                        : Runs in detached mode (background)

===============================================================================
STEP 3: RUN MYSQL CONTAINER WITH DATA PERSISTENCE (RECOMMENDED)
===============================================================================

To persist data even after container stops, use volumes:

    docker run --name blog-mysql ^
        -e MYSQL_ROOT_PASSWORD=rootpassword ^
        -e MYSQL_DATABASE=blogdb ^
        -e MYSQL_USER=bloguser ^
        -e MYSQL_PASSWORD=blogpass ^
        -p 3306:3306 ^
        -v blog-mysql-data:/var/lib/mysql ^
        -d mysql:8.0

The -v flag creates a named volume 'blog-mysql-data' that persists data.

===============================================================================
STEP 4: VERIFY CONTAINER IS RUNNING
===============================================================================

Check running containers:

    docker ps

You should see 'blog-mysql' in the list.

Check container logs:

    docker logs blog-mysql

Wait until you see: "mysqld: ready for connections"

===============================================================================
STEP 5: CONNECT TO MYSQL CONTAINER
===============================================================================

Method 1: Using MySQL client inside container

    docker exec -it blog-mysql mysql -u bloguser -p

Enter password: blogpass

Method 2: Using MySQL client on host machine

    mysql -h 127.0.0.1 -P 3306 -u bloguser -p

Method 3: Using root user

    docker exec -it blog-mysql mysql -u root -p

Enter password: rootpassword

===============================================================================
STEP 6: BASIC MYSQL COMMANDS (INSIDE MYSQL CLIENT)
===============================================================================

Show databases:
    SHOW DATABASES;

Select database:
    USE blogdb;

Show tables:
    SHOW TABLES;

Exit MySQL client:
    EXIT;

===============================================================================
STEP 7: UPDATE SPRING BOOT APPLICATION.PROPERTIES
===============================================================================

Update src/main/resources/application.properties:

    # MySQL Database Configuration
    spring.datasource.url=jdbc:mysql://localhost:3306/blogdb
    spring.datasource.username=bloguser
    spring.datasource.password=blogpass
    spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

    # JPA/Hibernate Configuration
    spring.jpa.hibernate.ddl-auto=update
    spring.jpa.show-sql=true
    spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect
    spring.jpa.properties.hibernate.format_sql=true

===============================================================================
STEP 8: ADD MYSQL DEPENDENCY TO POM.XML
===============================================================================

Add this dependency in the <dependencies> section of pom.xml:

    <dependency>
        <groupId>com.mysql</groupId>
        <artifactId>mysql-connector-j</artifactId>
        <scope>runtime</scope>
    </dependency>

Note: If using older Spring Boot versions, you might need:

    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-java</artifactId>
        <scope>runtime</scope>
    </dependency>

===============================================================================
STEP 9: CONTAINER MANAGEMENT COMMANDS
===============================================================================

Stop the container:
    docker stop blog-mysql

Start the container:
    docker start blog-mysql

Restart the container:
    docker restart blog-mysql

Remove the container (WARNING: loses data if no volume):
    docker rm blog-mysql

Remove the container (even if running):
    docker rm -f blog-mysql

View container logs:
    docker logs blog-mysql

Follow logs in real-time:
    docker logs -f blog-mysql

===============================================================================
STEP 10: DOCKER COMPOSE APPROACH (ALTERNATIVE)
===============================================================================

For easier management, create a docker-compose.yml file in project root:

version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: blog-mysql
    environment:
      MYSQL_ROOT_PASSWORD: rootpassword
      MYSQL_DATABASE: blogdb
      MYSQL_USER: bloguser
      MYSQL_PASSWORD: blogpass
    ports:
      - "3306:3306"
    volumes:
      - blog-mysql-data:/var/lib/mysql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 5

volumes:
  blog-mysql-data:

Then use these commands:

Start:
    docker-compose up -d

Stop:
    docker-compose down

View logs:
    docker-compose logs -f

===============================================================================
STEP 11: VOLUME MANAGEMENT
===============================================================================

List volumes:
    docker volume ls

Inspect volume:
    docker volume inspect blog-mysql-data

Remove volume (WARNING: deletes all data):
    docker volume rm blog-mysql-data

Backup volume data:
    docker exec blog-mysql mysqldump -u root -prootpassword blogdb > backup.sql

Restore from backup:
    docker exec -i blog-mysql mysql -u root -prootpassword blogdb < backup.sql

===============================================================================
STEP 12: TROUBLESHOOTING
===============================================================================

Problem: Port 3306 already in use
Solution: Use a different host port
    -p 3307:3306
    Then update application.properties to use port 3307

Problem: Container exits immediately
Solution: Check logs for errors
    docker logs blog-mysql

Problem: Connection refused from Spring Boot
Solution: Ensure container is running and healthy
    docker ps
    docker logs blog-mysql

Problem: Authentication plugin error
Solution: Use MySQL 5.7 or configure authentication:
    docker exec -it blog-mysql mysql -u root -p
    ALTER USER 'bloguser'@'%' IDENTIFIED WITH mysql_native_password BY 'blogpass';
    FLUSH PRIVILEGES;

===============================================================================
STEP 13: SECURITY BEST PRACTICES
===============================================================================

1. DO NOT use these simple passwords in production
2. Use strong, random passwords
3. Consider using environment variables or .env file for passwords
4. Do not commit passwords to version control
5. Restrict network access in production
6. Regularly backup your database
7. Keep MySQL image updated

===============================================================================
STEP 14: DEVELOPMENT WORKFLOW
===============================================================================

Daily workflow:

1. Start Docker Desktop
2. Start MySQL container:
   docker start blog-mysql

3. Verify it's running:
   docker ps

4. Start your Spring Boot application
5. Develop and test

6. (Optional) Stop container when done:
   docker stop blog-mysql

===============================================================================
STEP 15: CONNECTING FROM MYSQL WORKBENCH OR OTHER GUI TOOLS
===============================================================================

If you prefer a GUI tool like MySQL Workbench, DBeaver, or phpMyAdmin:

Connection settings:
- Hostname: 127.0.0.1 or localhost
- Port: 3306
- Username: bloguser (or root)
- Password: blogpass (or rootpassword)
- Database: blogdb

===============================================================================
USEFUL TIPS
===============================================================================

1. Named containers are easier to manage than using container IDs

2. Always use volumes for data persistence in development

3. Docker Desktop UI provides a convenient way to manage containers

4. You can have multiple MySQL containers on different ports for 
   different projects

5. Consider creating shell scripts or batch files for common commands

6. Use docker-compose for managing multiple containers (e.g., MySQL + Redis)
